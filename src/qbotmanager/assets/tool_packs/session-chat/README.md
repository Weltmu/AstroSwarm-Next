# 连续对话能力包

群里 @ 过机器人之后，**接下来一段时间不用再 @** 也能接着聊。以前每次说话都得 @ 一遍，
聊起来像在按门铃。

## 你能调什么

| 参数 | 说明 | 默认 |
|---|---|---|
| 开启免 @ 连续对话 | 关掉后群里只有 @ 它才回 | 开 |
| 怎么判断该不该接话 | **超时断开**（推荐）/ **读群聊天记录判断** | 超时断开 |
| 连续对话有效期 | 30~300 秒，只在"超时断开"模式下有用 | 30 秒 |
| 连着几句无关就停 | 连着这么多句没提到它，就当这次对话结束了 | 5 句 |

参数在控制台「插件 → 已装能力包 → 配置」里改，改完重启一次机器人生效。

## 两种判断方式的区别

- **超时断开**：被 @ 之后开一个时间窗（默认 30 秒，可调到 300 秒）。窗口里你接着说话，
  它会先看"上一条是不是回的你"，不确定时再让 AI 判一句要不要接。省钱、够用。
- **读群聊天记录判断**：不看时间，群里**每条**消息都交给 AI 看一遍群聊最近记录
  （带上发送者身份区分人）再决定接不接。更聪明，但群里热闹时 token 消耗明显上升。

## 和其他行为的关系

- 别人 @ 别人时它不会抢话（这是默认行为，任何模式下都一样）。
- 判断失败（比如模型超时）一律**不回复**并写日志，绝不会发一句写死的兜底话术。
- 想让它在群里主动找话题，那是另一个包：**主动聊天能力包**的"群里搭话"。
